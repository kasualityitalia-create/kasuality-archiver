## 2. Full Description (AlternativeTo, Microsoft Store, GitHub)
**Kasuality Archiver** is a 100% free, zero-ads, zero-nag-screen archive manager built by Kasuality (`https://kasuality.com`).

Why switch from legacy archivers?
- **Quick Look without extracting**: preview text, code, JSON, Markdown, and images directly in memory without cluttering your disk with temporary files.
- **Zero-Trust Security Scan**: detects path traversal (`../../`) and suspicious double extensions (such as `invoice.pdf.exe`) before extraction.
- **Full-Text Search inside archives**: find keywords or code lines across compressed files without unpacking.
- **Extract All or Selected Only**: extract the entire archive or right-click to extract only selected files.
- **Smart Dev Exclude**: automatically skips `node_modules`, `.git`, `__pycache__`, `dist`, and `.venv` when compressing project folders.
- **Modern Formats + SHA-256**: supports `.zip`, `.7z`, `.tar.zst` (Zstandard), `.tar.gz`, `.tar`, `.tar.bz2`, `.tar.xz`, with instant SHA-256 verification.
- **5 Languages Built-In**: English, Italian, French, Spanish, and German.
